This project is a custom light-up skull keychain designed using TinkerCAD. Inside the 3D-printed skull housing, a compact 3V coin cell battery sits snugly against the prongs of a small LED, creating a simple direct-contact circuit that illuminates the skull from within. In this initial prototype, the LED remains continuously lit whenever the battery is inserted, though the components can be easily swapped out or replaced. Looking ahead, the design can be upgraded by integrating a small circuit board, which would allow the LED to be programmed to cycle through different colors or turn on and off on command.
